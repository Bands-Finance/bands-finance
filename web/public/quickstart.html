02 How the rail works

A priced call with no payment gets HTTP 402 and the terms: 

{"x402Version":1,
 "accepts":[{
  "scheme":"exact",
  "network":"solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp",
  "asset":"EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
  "maxAmountRequired":"20000",        // $0.02, USDC 6-decimals
  "resource":"bands_screen",
  "payTo":"<the payee's USDC token account>",
  "description":"bands.finance bands_screen - $0.0200"
 }],
 "proof":{
  "header":"X-PAYMENT",
  "format":"base64(JSON) or raw JSON: { \"signature\": \"<tx signature>\", \"proofSignature\": \"<base64 or base58 ed25519 signature over signMessage>\" }",
  "signMessage":"bands.finance x402 payment authorization\nCluster: mainnet-beta\nTreasury: <payTo>\nResource: bands_screen\nTx: <your payment tx signature>",
  "note":"Sign the message above with the wallet that SENT the USDC ..."
 }}

Send maxAmountRequired USDC to payTo, sign signMessage with the real tx signature in it, and retry with an X-PAYMENT header: base64({"signature":"…","proofSignature":"…"}). The transfer must cover the price, be under 15 minutes old, and buys one call.

03 The whole client

import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";
import { Connection, Keypair, PublicKey, Transaction, sendAndConfirmTransaction } from "@solana/web3.js";
import { createTransferCheckedInstruction, getAssociatedTokenAddressSync } from "@solana/spl-token";
import nacl from "tweetnacl";

const BANDS = process.env.BANDS_API_URL + "/mcp";      // the host running Mr Bands' API
const USDC = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v");
const connection = new Connection(process.env.RPC_URL!, "confirmed");
const agent = Keypair.fromSecretKey(Uint8Array.from(JSON.parse(process.env.AGENT_KEY!)));

async function callOnce(tool: string, args: object, payment?: string) {
  const transport = new StreamableHTTPClientTransport(new URL(BANDS),
    { requestInit: { headers: payment ? { "X-PAYMENT": payment } : {} } });
  const client = new Client({ name: "my-agent", version: "1.0.0" });
  await client.connect(transport);
  try { return await client.callTool({ name: tool, arguments: args }); }
  finally { await client.close(); }
}

export async function paidCall(tool: string, args: object = {}) {
  try { return await callOnce(tool, args); }        // free tools answer here
  catch (err) {
    const msg = String((err as Error).message);
    const at = msg.indexOf('{"x402Version"');
    if (at < 0) throw err;                       // not a payment challenge
    const challenge = JSON.parse(msg.slice(at));
    const terms = challenge.accepts[0];
    if (terms.network !== "solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp" || terms.asset !== USDC.toBase58()) throw err;

    // pay: one USDC TransferChecked for the quoted amount, from your token account to payTo
    const source = getAssociatedTokenAddressSync(USDC, agent.publicKey);
    const tx = new Transaction().add(createTransferCheckedInstruction(
      source, USDC, new PublicKey(terms.payTo), agent.publicKey, BigInt(terms.maxAmountRequired), 6));
    const signature = await sendAndConfirmTransaction(connection, tx, [agent], { commitment: "confirmed" });

    // prove the payment is yours: sign the challenge's message with the real tx signature in it
    const message = challenge.proof.signMessage.replace("<your payment tx signature>", signature);
    const proofSignature = Buffer.from(
      nacl.sign.detached(new TextEncoder().encode(message), agent.secretKey)).toString("base64");

    // retry with proof
    const payment = Buffer.from(JSON.stringify({ signature, proofSignature })).toString("base64");
    return await callOnce(tool, args, payment);
  }
}

// first paid call: the full ranked board, $0.02
console.log(await paidCall("bands_screen"));

05 Verify

GET /api/revenue shows the payee and what the tools have earned. A failed payment returns the reason: payment tx already used, payment tx too old, insufficient payment, or signature does not match the wallet that sent this payment.

Signed-in wallets with access can run the engine on their own capital: GET /api/engine/skill.
